# Villa.Net Avito — обязательный стандарт

- График во всех объявлениях: 7 дней в неделю, ежедневно с 08:00 до 22:00.
- Базовая цена объявления и настройки Wi‑Fi/роутера/модема: 2 500 ₽.
- Не использовать цену 2 600 ₽.
- Не добавлять услугу «Настройка сервера» в объявления про загородный интернет.
- Первая фотография: фирменная городская карточка Villa.Net.
- Третья фотография: подтверждённый замер скорости интернета.
- Один населённый пункт — одно активное объявление Villa.Net; перед загрузкой сверять фид с уже активными и заблокированными карточками Avito.
- Не создавать новый ID для города, если существующую активную карточку можно обновить без повторного размещения.
- Внутри одного объявления не повторять фотографии; между объявлениями одного города не дублировать заголовок, описание и обложку.
- Платное продвижение включается только после отдельного подтверждения.
